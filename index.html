想重新来过？

独立账本 = 在云端新建两张专属数据表（编号-流水 + 编号-设置），流水默认空数据开始、时薪参数自动带入，你的数据与别人互不可见；把页面地址或账本编号发给另一台设备打开，即同一本账。

使用说明

· 数据存在在线 KVdb 数据表（每个账本两张：流水表 + 设置表），记一笔、改一笔、删一笔都会即时写回云端。
· 换手机/换浏览器：点上方「创建我的独立账本」拿到编号，在新设备输入编号（或打开同一链接）即接上同一本账。
· iOS：Safari 打开本页 → 分享 → 添加到主屏幕，像 App 一样使用。
· 微信：把链接发到聊天里即可在微信内打开记录。
· 免费 KVdb 桶约 3 个月未访问会过期，页面会提前提醒；也可随时导出 JSON 备份再导入。
· 正式长期使用建议换成自己的 Supabase / 云开发数据表，只需替换顶部 CONFIG 里的地址和读写函数。
