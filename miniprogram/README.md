# 打工人小账本 · 微信小程序壳（web-view 方案）

用 `<web-view>` 把已部署的 H5 记账页装进小程序。壳子本身只有 6 个文件，逻辑全在 H5。

## ⚠️ 先确认两个硬前提（缺一不可）

1. **小程序主体必须是非个人类型**（企业/个体工商户/组织）。微信官方限制：个人主体小程序**不支持 web-view 组件**。注册个人小程序走不了这条路。
2. **H5 域名必须 ICP 备案 + HTTPS**，并通过微信的域名归属验证。`github.io` / `lhr.life` 这类域名**无法配置为业务域名**。

## 前置材料清单

- [ ] 非个人主体小程序账号（mp.weixin.qq.com 注册，需营业执照/组织证照，企业主体需微信认证）
- [ ] 一个自己的域名（腾讯云/阿里云购买，`.com` 首年几十元）
- [ ] ICP 备案（跟着云厂商流程，个人也能给域名备案，审核约 1~3 周）
- [ ] 国内静态托管：推荐**腾讯云 COS 开启静态网站 + 绑定已备案域名 + 免费 SSL 证书**（也可用宝塔/Nginx 服务器）

## 部署步骤

### 1. 把 H5 部署到你的备案域名
把 `penny-ledger` 仓库里的 `index.html`（及需要的文件）上传到腾讯云 COS 存储桶（开启静态网站功能），绑定自定义域名 `ledger.xxx.com` 并配 HTTPS。
验证：浏览器打开 `https://ledger.xxx.com` 能看到账本即成功。**数据同步不用改任何东西**——kvdb.io 对任意 https 域开放 CORS，换浏览器 localStorage 按域隔离也不影响（编号找回机制保证跨域换设备）。

### 2. 配置业务域名（关键）
mp.weixin.qq.com → 开发管理 → 开发设置 → **业务域名** → 添加 `ledger.xxx.com`：
- 下载微信给的校验文件（形如 `XXXX.txt`），上传到 COS 桶**根目录**，确保 `https://ledger.xxx.com/XXXX.txt` 可访问后再保存。
- 协议只支持 https，域名需已备案。

### 3. 配置壳子并本地预览
1. 安装「微信开发者工具」，用小程序管理员微信扫码登录。
2. 导入本项目目录（`miniprogram/`），AppID 填你的（或在 `project.config.json` 里替换 `你的AppID`）。
3. 改 `app.js`：`WEB_URL: "https://ledger.xxx.com/"`。
4. 本地调试时 `urlCheck` 已关（见 `project.private.config.json`），可直接在模拟器里看到 H5；真机预览需业务域名配置完成。

### 4. 上传、提审、发布
开发者工具 → 上传 → 版本管理 → 提交审核：
- **类目**建议选「工具 > 效率」；别选金融类目（记账类若被归金融需要资质）。
- 审核简介里说明：记账工具，数据云端同步，附功能截图。
- web-view 类小程序常见驳回理由：空壳/引导分享/类目不符。若因「内容过于简单」被拒，在 H5 里补充设置页说明、隐私政策页后重提。
- 审核通过后 → 全量发布 → 微信搜索可达。

## 与多账本机制的配合

H5 里「创建我的独立账本」生成的编号机制在小程序内照常工作；发给同事的链接换成 `https://ledger.xxx.com/?ledger=编号`，在小程序里打开对应 URL 也一致。
